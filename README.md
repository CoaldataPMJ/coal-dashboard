# 中国煤炭高频数据看板

用煤炭 Excel 数据库生成总览周报图表、周报指标，以及动力煤、炼焦煤、海外能源、产量及进口明细。

## 查看网页

下载或克隆仓库后，直接用浏览器打开 `index.html`。网页不依赖外部图表 CDN，可离线查看。总览包含4个摘要卡片，以及按“周报输出”生成的六张图和指标明细，支持日期筛选、图例切换、分类、搜索和 CSV 下载。2026-11-20 版周报有41项指标。

总览图项依次为港口5500动力煤价格、国际动力煤价格、二十五省动力煤日耗、二十五省动力煤库存、炼焦煤价格、日均铁水产量。年度图按1–12月叠加，用图例选择年份。连续图使用顶部的起止日期。

顶部「动力煤」进入价格、港口库存、港口运输、二十五省电厂汇总、内陆十七省电厂、沿海八省电厂、下游月度发电、下游旬度发电、三峡出库流量、下游化工周度、分行业煤耗、动力煤分国别进口十二组图表。进口到岸美元仅展示进口4700和进口3800。

顶部「炼焦煤」依次展示炼焦煤价格、247家钢厂高炉开工率、炼焦煤库存与下游开工率、炼焦煤下游产量、炼焦煤分国别进口。钢厂组中保留日均铁水产量和高炉开工率两项图表。

顶部「海外能源」分为「国际原油价格」「海外天然气价格」，展示WTI、布伦特、阿曼原油，以及NYMEX Henry Hub和ICE TTF天然气。不同单位的天然气价格分图展示。

顶部「产量及进口」展示国内煤炭产量、煤炭进口总量、分国别进口、主要产地月度产量、主要产地周度产量。月度值、累计值、产量增速、开工率分别分图。

各明细板块独立保存筛选条件，支持连续时间序列和年度对比。时间范围限定为2021–2026，可按年份或自定义起止日期筛选。年度对比以1–12月叠加原频率走势，可勾选年份和月份；2026年统一使用加粗的明黄色曲线。

鼠标移动到曲线附近时高亮实际数据点，提示该点的数值及周环比、旬环比或月环比、同比。支持触摸点按和左右方向键。不展示比较基期日期、分摊或推算备注。缺失值显示“—”，线图保留缺口；二十五省电厂汇总跳过零值，其他指标按各自源表口径处理。

## 首次发布到 GitHub Pages

1. 在自己的 GitHub 账号中新建名为 `coal-dashboard` 的公开仓库。
2. 将本目录文件放到仓库根目录。现有站点升级时一次替换网页及数据文件，并保存本目录的六个 Python 文件。
3. 进入仓库 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，保存。
5. 发布完成后使用 GitHub Pages 页面给出的实际网址。

官方说明：[配置 GitHub Pages 发布源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。本地文件准备好不代表已经在 GitHub 创建仓库或发布成功。

## 每次更新数据

先在 Excel 中更新、计算并保存数据库。Python 使用 Excel 已保存的计算结果，不会重新计算公式。

需要 Python 3.9 或更新版本。首次安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

### Mac

在本目录打开终端。默认从当前用户桌面的“周报日报数据库”文件夹选择文件名日期最新的数据库：

```bash
bash 更新数据.command
```

也可以明确指定 Excel 或其所在文件夹：

```bash
bash 更新数据.command "/完整路径/China Coal Database-20261113.xlsx"
```

### Windows PowerShell

在本目录打开 PowerShell，首次安装依赖：

```powershell
python -m pip install -r .\requirements.txt
```

指定本机的 Excel 路径运行：

```powershell
.\update_data.ps1 -Source "C:\你的文件夹\China Coal Database-20261113.xlsx"
```

如果 PowerShell 不允许执行脚本，可直接执行 Python 命令：

```powershell
python .\extract_dashboard_data.py --source "C:\你的文件夹\China Coal Database-20261113.xlsx" --output-dir .
```

### 通用 Python 命令

```bash
python3 extract_dashboard_data.py --source "/完整路径/China Coal Database-20261113.xlsx" --output-dir .
```

生成的 `data.js` 位于本目录，替换网页数据。辅助文件 `data.json` 和 `extraction_report.json` 保留在本地，由 `.gitignore` 排除。运行成功后查看输出和提取报告，再将 `data.js` 上传到 GitHub 仓库根目录，或在已克隆的仓库中执行：

```bash
git add data.js
git commit -m "Update coal dashboard data"
git push origin main
```

已配置为 `main` 根目录发布的 GitHub Pages 会根据该分支的更新重新发布。只有原始数据库更新、没有重新生成和提交 `data.js` 时，线上网页数据不会改变。

## 数据范围与单位

- `thermal_data.py` 集中维护动力煤指标的 Excel 列位置、表头和单位。港口库存读取 `动力煤-港口库存` 的B、E、H、K、N列，分别展示长江口、北方港、CCTD主流港口合计、沿海、内河。
- 三峡出库流量在动力煤下单列分组，读取 `动力煤-下游旬度` 的CN列日期、CO列日度出库流量，单位立方米/秒。
- 分行业煤耗取 `动力煤-分行业煤耗` A 列统计月和 B:O 的当月值、年初至今累计值。保留原表总消费量和电力、供热、建材、冶金、化工、其他行业六项，单位万吨。
- 分国别进口取 `产量及进口` A 列和「动力煤分国别进口量」区块 AW:AZ，显示澳大利亚、印度尼西亚、俄罗斯和其他。原表千吨乘 0.1 换为万吨，采用原表「其他」分类和已报出的零值。
- 动力煤的日度环比按上月同日，周度按上一统计周，旬度按上一旬，月度按上月。同比按上年对应期。已核验的原表同比优先，百分点及绝对差额单列。下游月度发电仅使用源表已保存的同环比，未报出的比较值显示“—”。
- 炼焦煤「247家钢厂高炉开工率」取 `钢铁` 的 A/B/C 列，按周显示 247 家样本钢厂的日均铁水产量（万吨/日）与高炉开工率。开工率的周环比和同周同比以百分点显示。
- 炼焦煤价格和库存沿 `炼焦煤-价格` 与 `炼焦煤-库存及开工率` 的公式追溯到底表，用实际报价日和观测日。喷吹煤单列分图。库存与可用天数保持 110 家钢厂、100 家独立焦化厂各自的样本定义。
- 炼焦煤下游取 `炼焦煤-下游 ` 的 B:P 列，覆盖焦炭、生铁、粗钢的产量、月度增速和累计口径。炼焦煤分国别进口读取 `产量及进口` BA:BE，原表千吨换算为万吨，美国及加拿大沿用合并项。
- `overseas_data.py` 读取 `国际能源` G列日期、H/I/J列WTI、布伦特和阿曼原油；天然气沿现有价格底表取数。
- `supply_data.py` 读取 `产量及进口`、`主要产地月度产量`、`主要产地周度产量`。百万吨换算为万吨、千吨换算为万吨；原表百分数与小数比例分别转换。原煤和炼焦煤当月产量、累计产量、进口总量优先使用源表比较值。主要产地包括全国、山西、内蒙古、陕西、新疆；周度为三省合计及山西、内蒙古、陕西。
- 总览图表由 `weekly_charts.py` 读取“周报输出”中图表的实际 Excel 单元格引用，按图表在表内的排布顺序导出，保留原表的缺失值和已保存计算结果，统一限制在2021–2026。图表模板变化时检查图名与引用校验。
- 总览表格直接读取“周报输出”的名称、单位、本期、前期、环比、去年同期、同比、备注。电厂周报区间均值和煤种明细的单日值分别保留。
- 文件名日期、目录日期、周报日期及明细最后有效观测期分别记录。本次文件名和周报日期为2026-11-20，目录日期为2026-11-22。总览年度图按周报日期截止，煤种明细保留各自实际观测期。
- 周报的铁水图使用原图的月度均值表，该表当前年仅保存至9月。炼焦煤明细中的周度日均铁水序列更新至11月20日。

原始 Excel 留在本机，`.gitignore` 排除了 Excel 文件。发布在公开网页上的 `data.js` 可以被访问者读取。

## 文件职责

| 文件 | 用途 |
|---|---|
| `index.html` | 页面结构 |
| `styles.css` | 桌面、手机和打印样式 |
| `app.js` | 图表、表格、交互和缺失值格式化 |
| `thermal.js` | 四个明细板块共享的分组、双视图、筛选和同环比提示 |
| `data.js` | 从 Excel 导出的网页数据 |
| `extract_dashboard_data.py` | Excel 提取与布局校验 |
| `weekly_charts.py` | 读取“周报输出”六张图的单元格引用及年度图布局 |
| `thermal_data.py` | 动力煤取数配置、基期匹配和数据质量处理 |
| `coking_data.py` | 炼焦煤和钢铁样本指标的取数配置 |
| `overseas_data.py` | 国际原油和天然气的取数配置 |
| `supply_data.py` | 煤炭产量、进口及主要产地指标的取数配置 |
| `requirements.txt` | Python 依赖 |
| `更新数据.command` | Mac 本地更新入口 |
| `update_data.ps1` | Windows PowerShell 本地更新入口 |
| `.nojekyll` | 让 GitHub Pages 直接提供静态文件 |

布局调整时，在对应板块的取数配置中修改表名、列、表头和单位。更新入口先验证并写入临时数据，成功后再替换 `data.js`。运行报告包含各明细序列的真实覆盖、缺失原因和重复项。
